Hermes VPS Backup

Hermes VPS Backup is a privately operated, single-user backup system. It creates encrypted backups of application data and transfers them to the owner's private Google Drive.

How it works

Restic creates encrypted backup repositories on a privately managed virtual private server. Rclone transfers the encrypted repository to Google Drive using the Google Drive API.

Google Drive access

The application uses Google Drive authorization to manage its own backup files. It is intended solely for the owner's personal backup system, not as a service for other users.

Privacy

Backup contents are encrypted before transfer. This website does not host backup files, collect Google Drive credentials, or provide access to the owner's Google Drive.
