Privacy Policy

Last updated: October 31, 2026

1. About this application

Hermes VPS Backup is a privately operated, single-user backup utility. It is not a public service and is not offered to other users.

2. Information processed

The application processes information necessary to maintain backups, including:

  • Google OAuth authorization data used to access the operator's Google Drive.
  • Backup files containing Hermes application configuration, state, and other selected system data.
  • Operational information such as backup timestamps, repository metadata, and job logs.

3. How information is used

Restic encrypts backup repository contents before they are transferred. Rclone transfers the encrypted repository to the operator's private Google Drive using the Google Drive API.

Google authorization data is used only to authenticate requests and manage the application's backup files. It is stored in protected configuration on the operator's private server.

4. Sharing and third-party services

The application does not sell personal information, display advertising, or provide backup data to unrelated third parties.

Google Drive is used as the remote storage provider. Google processes information associated with its services under its own privacy policies.

The public informational website is hosted by GitHub Pages. GitHub may process technical information associated with website requests under its own privacy policy.

5. Security

Backup repository contents are encrypted by Restic before upload. Access to the server, authorization credentials, and encryption password is restricted to the operator.

The Restic encryption password is essential for restoring backups. Losing it may make the backup data unrecoverable.

6. Retention and deletion

Backup retention is controlled by the operator's configured backup schedule and retention policy. The operator can remove backup data from the remote repository.

7. Website information

This informational website does not provide account registration, contact forms, advertising, or analytics. It does not host backup archives or Google authorization credentials.

8. Changes to this policy

This policy may be updated if the backup system or its data-handling practices change.

9. Contact

Questions about this application or this policy can be submitted through the GitHub repository . Please do not include passwords, credentials, or other sensitive information in public issues.
